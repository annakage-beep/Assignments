#  Programming Assignments 


## Assignment Overview

The objectives of these assignments are to apply programming logic to solve real-world calculation and matrix processing problems while evaluating design choices between procedural and Object-Oriented Programming (OOP) architectures. 

Each solution in this repository contains:
1. **Source Code:** The optimized C++ implementation file.
2. **Documentation (`.md`):** A comprehensive breakdown explaining the OOP concepts used (or procedural alternatives), the core algorithm steps, and potential runtime error points.

### Included Problems

* **Problem 1: Credit Card Validation**
  * **Objective:** Implement a security algorithm to validate numeric inputs representing credit card numbers. 
  * **Core Focus:** Working with large numeric types (`long long`), string-like digit extraction arithmetic, and implementing **Luhn's Algorithm** (Mod 10 validation).

* **Problem 2: Grading Multiple Choice Questions**
  * **Objective:** Automate the grading process for a classroom of students taking a multiple-choice examination.
  * **Core Focus:** Multi-dimensional matrix traversal (2D arrays), nested loop logic, and index-matched data comparison against a static key array.
